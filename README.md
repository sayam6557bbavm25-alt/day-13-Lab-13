Topic:* Document-Grounded Question Answering (RAG)

•⁠  ⁠*Goal:* Compare a normal/ungrounded AI answer with an answer based only on an uploaded airline policy document.
•⁠  ⁠*Main concept:* *RAG = Retrieval-Augmented Generation* — AI retrieves relevant information from a document before generating an answer.
•⁠  ⁠*Main activity:*

  1. Ask AI a policy question *without* the document.
  2. Upload the instructor’s fictional airline policy.
  3. Ask the same question using *only the document*.
  4. Compare both answers.
  5. Verify at least *4 claims and citations* against the original document.
•⁠  ⁠*Verification method:* *Claim → Source → Match → Context → Action*
•⁠  ⁠*System testing:* Check whether AI guesses when information is missing, invents compensation/refund rules, or provides private information.
•⁠  ⁠*Passenger response:* Create a short, professional response using only verified policy information.
•⁠  ⁠*Risk audit:* Check outdated documents, missing information, wrong retrieval, citation errors, missed exceptions, privacy and lack of human approval.
•⁠  ⁠*Reflection:* 150–200 words on how grounding improved the answer and why human verification is still needed.
